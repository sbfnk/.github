# .github

This repository holds the default review specification for sbfnk repositories.

- `REVIEW.md`: the general half of the code review specification, covering what to review (a PR, the commits since a given one, or the working diff), what counts as a finding, what to check before calling a change clean, and how to report. It is the org-wide specification from `epiforecasts/.github` with a general opening. A repository can add its own `.github/REVIEW.md` with what to look for in that codebase, and a review then follows both.
